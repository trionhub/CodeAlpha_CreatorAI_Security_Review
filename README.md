# Secure Coding Review of CreatorAI Dashboard

## CodeAlpha Cyber Security Internship – Task 3

### Project Overview

This project presents a security assessment of a simple AI content creator platform called **CreatorAI Dashboard**. The objective of the review was to identify security vulnerabilities, assess their impact, and recommend secure coding practices.

The application simulates common features found in modern creator platforms, including:

* User Authentication
* Thumbnail Upload Simulation
* Email Handling
* API Key Integration

---

## Technologies Used

* Python 3.14.5
* Windows Command Prompt
* Microsoft Word
* GitHub
* Manual Code Review

---

## Security Vulnerabilities Identified

### 1. Hardcoded Credentials

* Severity: High
* Risk: Unauthorized access through exposed credentials.

### 2. Exposed API Key

* Severity: High
* Risk: Abuse of paid AI services.

### 3. Unsafe File Upload

* Severity: High
* Risk: Malicious file uploads.

### 4. Unlimited Login Attempts

* Severity: Medium
* Risk: Brute-force attacks.

### 5. User Data Exposure

* Severity: Medium
* Risk: Leakage of sensitive information.
